# 📚 BookHive - Online Book Shopping Site

Welcome to **BookHive**, a modern web application for browsing, discovering, and purchasing books online.

---

## ✨ Features

- 🏠 **Home Page**: Featured deal of the day, trending collections, hero section, and category highlights.
- 📚 **Book Catalog & Filtering**: Browse through extensive book collections with category and price filters.
- 🏷️ **Categories**: Explore genres including Fiction, Non-Fiction, Sci-Fi, Mystery, Biography, and more.
- 🛒 **Shopping Cart & Checkout**: Interactive shopping cart management, seamless checkout simulation, and order confirmation.
- 📜 **Order History**: Track past orders and order status.
- 🎁 **Offers & New Arrivals**: Dedicated sections for ongoing deals and newly added titles.
- 👤 **User Authentication**: Login & registration modal interfaces.

---

## 🛠️ Tech Stack

- **HTML5 & CSS3** (Vanilla CSS with flexbox/grid layout and modern styling)
- **JavaScript (ES6+)** for dynamic UI interactions, local storage persistence, and cart management
- **FontAwesome 6** icons
